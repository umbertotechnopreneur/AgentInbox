# Provider logos

The Linux setup UI loads provider images from this directory. Gmail uses the Google mark and Microsoft 365 uses the Microsoft mark.

- Google: https://cdn.svgporn.com/logos/google-icon.svg
- Microsoft: https://cdn.svgporn.com/logos/microsoft-icon.svg

Downloaded on 2026-09-06 from the [SVG Logos collection](https://github.com/gilbarbara/logos). Provider marks identify compatibility and remain the property of their respective owners; the project's MIT license does not grant trademark rights.


The colored cloud, Outlook.com mailbox and custom server badges are original AgentInbox artwork under the project MIT license.
